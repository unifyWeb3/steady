# 14 — Substitution Analysis

"What does user do instead?"

| Problem | Substitutes | Why substitute wins today | Where we beat it |
|---------|-------------|---------------------------|------------------|
| Sizing | Spreadsheet, mental math, "just YOLO 50 tUSDC" | Faster, no new tool | We convert max loss → contracts in one tap with live book |
| Tilt | Discord, Telegram, "take break" manual | Social friction, self-control | Automatic cooldown + Brier drift is undeniable data |
| Skill vs luck | PnL glance, spreadsheets, gut | PnL is immediate | Brier/Edge is honest over 5+ calls |
| Redemption | Do nothing, wait for DreamDEX to airdrop (never), manual explorer | Forgetfulness is easier | Auto-inbox with claimable count + one-click |
| Discovery | DreamDEX app scroll, X calls | Single venue, habit | Tradability ranking (headroom, spread, depth) saves gas |
| Settlement trust | Trust team, check explorer manually | Explorer is buried | Deep-link per market to oracle graph + median proof |
| Execution safety | Retry until not revert | Gas is cheap on testnet | Pre-check status/tick/lot/expiry before sign saves gas + UX |
| Learning | YouTube, docs | Content is generic | Live Brier coaching in the same UI as the next trade |

Spreadsheet, Telegram group, manual workflow, doing nothing are the real competitors — not just other startups.
